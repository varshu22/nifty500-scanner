# Nifty 500 Daily Scanner

Automated Nifty 500 scanner running 3x daily on weekdays.

**Live Dashboard:** https://varshu22.github.io/nifty500-scanner/

## Schedule (IST)
- 9:45 AM — pre-market read
- 1:20 PM — midday check
- 5:30 PM — EOD analysis

## What it tracks
21-day candles, RSI (daily + weekly), EMA 9/50, 4-module confluence, 7 structural patterns, sector pulse.

Built with Python + GitHub Actions. Output rendered as a static dashboard via GitHub Pages.
